# MVC Calculator using Java Swing

This project is a **Java Swing Calculator** developed using the **MVC (Model-View-Controller) architecture**. It performs basic mathematical operations and demonstrates separation of calculation logic, user interface, and user actions.

### Technologies

* Java
* Java Swing
* MVC Architecture
* OOP Concepts

### Components

* **Model:** Performs calculations.
* **View:** Displays the calculator GUI.
* **Controller:** Handles user interactions.

### How to Run

Compile and run the Java project using any Java IDE such as **VS Code, IntelliJ IDEA, or Eclipse**.
